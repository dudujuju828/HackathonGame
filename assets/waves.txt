# waves.txt — wave definitions, parsed at startup.
#
# Format:
#   WAVE "Display Name" duration_sec
#   GROUP at_sec  Name count [Name count ...]
#
# - Groups within a wave fire when wave-elapsed >= at_sec.
# - The wave ends after duration_sec (any unspawned groups skip).
# - Enemy names are case-insensitive: Harpy, Bulldog, Cat, Pig, Chicken.
# - Comments (#) and blank lines are ignored.
#
# Design notes (game-designer pass):
#  - Wave 1-2: tutorial pacing, just Cat and Chicken (low HP). Player learns
#    movement, manual fire, and the rhythm of the auto-ring if they get one.
#  - Wave 3 introduces Harpy. Wave 5 introduces Bulldog (the first real tank).
#    Wave 7 introduces Pig (medium tank, slow drop pacing).
#  - Each wave has 3-5 groups with breathing room between them so the
#    player can collect chests without being immediately swarmed.
#  - Final wave (10) is climactic: every type, sustained pressure, no breather.
